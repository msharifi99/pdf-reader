Conventions
- Svelte 5 runes only (`$state`, `$derived`, `$effect`, `$props`), TypeScript strict. No UI framework libraries (no Tailwind, no component kits). Plain CSS using the tokens in `lib/design/tokens.css`.
- Every user action is a Command (`commands.register({...})`), triggered through `commands.execute(id, args)`. UI buttons call commands, never business logic directly.
- All colours, radii, spacing, shadows, durations come from CSS custom properties. No hard-coded colours in components.
- Engines never import UI code. UI never branches on format; it talks to `Engine`.
- Large files are never read whole into JS: the webview fetches `quire://localhost/book/<id>` (Range-capable) in Tauri, and `/fixtures/...` in the fake core.
- Heavy work off the UI thread (Rust threads or Web Workers).
